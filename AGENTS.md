# Project instructions

Read [docs/AGENTS.md](docs/AGENTS.md) and the relevant core documents before substantial work. That file centralizes this project's agent instructions; keep this root file as a discovery pointer.

Part 7 adds the Ollama embedding adapter with the Nomic prefixes, bounded retry, and vector validation under apps/api; it is approved and published on origin/main. Embedding sends `truncate: false` so over-long input errors instead of being silently trimmed, validates exactly 768 finite values, re-reads the model digest before every embedding and fails closed when it differs from the required `OLLAMA_EMBED_DIGEST`, and bounds each attempt with a real wall-clock deadline. Part 8 then adds the durable ingestion worker under apps/api/app/ingestion with the manager upload routes in apps/api/app/api/manager.py: a `.md`/`.txt` upload is validated before any write, staged as a pending job with a server-generated document id and revision, claimed with FOR UPDATE SKIP LOCKED under a 120-second lease renewed every 30 seconds, and every staging write and activation is fenced on a per-claim token and on the lease expiry, so an expired lease is refused even when nobody reclaimed the job; the expiry is compared against the database's live clock rather than now(), because now() is the transaction start time and goes stale while a transaction waits on a lock; a statement's qualification is also evaluated before its wait, so the check is repeated after the lock is held, and activation repeats it once more after its last lock (advisory, then job row, then document row) and immediately before any mutation, so no wait that outlives the lease can slip through. Activation is one transaction that compare-and-swaps the expected current revision and atomically reserves the chunk quota under the publisher lock, so a failed job leaves the previously published revision searchable and two concurrent publishers cannot both take the last room. The upload route parses no body until Origin and the manager role have been checked, and an ASGI guard caps the whole multipart body while streaming. It is approved and published on origin/main.
