# نسخهٔ انسانی پرسش‌های ارزیابی

> مجموعه و پاسخ‌های مرجع این سند baseline ساختگی‌اند و نتیجهٔ محصول زنده نیستند. تغییر بعدی ارزیابی در [راهنمای ارزیابی](evaluation-guide.md) و پارت ۳۵ برنامه تعریف شده است؛ آماده‌سازی مستندات، متن نمونه‌ها یا goldها را تغییر نمی‌دهد.

این فایل برای بازبینی انسانی تولید شده است؛ `eval/questions.jsonl` مرجع canonical داده‌هاست. شناسه، سؤال، رفتار مورد انتظار، پاسخ، حقایق لازم، منابع، اسناد ممنوع و یادداشت‌ها باید با همان رکورد JSONL هم‌خوان باشند.

این معیار فقط برای توسعه است. شناسه‌های سند، منبع را در DB ارزیابی جداگانه مشخص می‌کنند؛ فایل‌های اسناد مرجع در clone و image تولید نیستند.

## A06 — access_security (manager)

**سؤال:** در چه وضعی استثنای تجهیزات دورکاری لازم است و چه تأییدهایی باید پیش از خرید ثبت شده باشند؟

- تأیید مدیر عملیات و مالی پیش از خرید لازم است
- موافقت یک مرجع به‌تنهایی مجوز نیست

**منابع طلایی:**

- `MGR-001` — `MGR-001-S2`

**شناسه‌های سند ممنوع:**

- ندارد.

**یادداشت:** manager_authorized؛ همهٔ پاسخ‌ها از MGR-001-S2 پشتیبانی می‌شوند.
