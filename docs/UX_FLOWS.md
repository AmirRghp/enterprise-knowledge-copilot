# جریان‌های کاربر

وضعیت «موجود» از صفحه‌ها و API جاری می‌آید؛ مسیرهای «هدف» تا اجرای کارت مربوط قابل استفاده نیستند. ظاهر در [نظام طراحی](DESIGN_SYSTEM.md)، validation در [API](API.md) و رفتار شکست در [خطاها](ERROR_HANDLING.md) است.

## جریان‌های موجود

| جریان | پیش‌شرط و اقدام | موفقیت | loading / خالی / شکست |
|---|---|---|---|
| نصب و setup | DB/migration آماده، هیچ کاربری وجود ندارد؛ نام سازمان، نام‌ها، ایمیل و password ثبت شود. | یک مدیر و نشست و نام سازمان اتمی ساخته شوند؛ setup بسته شود. | درخواست هم‌زمان فقط یک برنده؛ validation در فرم؛ وجود کاربر صفحهٔ setup را برای همیشه می‌بندد. |
| ورود/خروج | login/password؛ هویت از cookie معتبر. | ورود به پوستهٔ نقش مجاز؛ logout نشست را revoke می‌کند. | خطای عمومی برای حساب ناموجود/غیرفعال/رمز غلط؛ 429 زمان retry دارد؛ secret در URL نیست. |
| تنظیم provider | مدیر اتصال chat/embedding را ثبت و test می‌کند. | اتصال آزموده فعال و مدل آمادهٔ استفاده می‌شود. | نصب خالی provider ندارد؛ failure با پیام امن؛ embedding نامتناسب قبل از activation رد می‌شود. |
| تغییر embedding | index پر و اتصال تازه آزموده است؛ مدیر هشدار متن/هزینه را تأیید کند. | reindex پایدار؛ cutover اتمی پس از تکمیل. | درصد/وضعیت بعد refresh حفظ؛ index قدیمی تا موفقیت؛ هنگام reindex upload/replace بسته است. |
| افزودن سند | مدیر یک فایلِ فرمت مجاز یا متن pasted، title و access_role می‌دهد. | job: pending → indexing → ready؛ سند قابل استفاده می‌شود. | rejected پیش از staging؛ failed با دلیل امن؛ هیچ سند نیمه‌آماده در retrieval نیست. |
| جایگزینی/حذف | مدیر سند را تغییر، narrow یا حذف می‌کند. | version آماده جای قبلی را اتمی می‌گیرد؛ کاهش دسترسی/حذف فوراً retrieval را قطع می‌کند. | شکست جایگزینی revision قبلی مجاز را حفظ می‌کند؛ source کهنه نامعتبر است. |
| گفت‌وگو | کاربر نشست معتبر و corpus مجاز دارد؛ سؤال ≤۲۰۰۰ نویسه. | turn pending و سپس answered با answer/citation یا امتناع صریح. | تاریخچهٔ خالی اقدام ساخت دارد؛ failed/retry/cancel جدا؛ retry همان turn؛ polling تک‌پرواز. |
| انتخاب تاریخچه | کاربر چت متعلق به خود را انتخاب/rename/delete می‌کند. | صفحهٔ انتخابی و عنوان حفظ؛ حذف فقط همان حساب. | پاسخ دیررس چت قدیمی انتخاب را برنمی‌گرداند؛ pending پس از restart قابل retry می‌شود. |
| بازکردن منبع | citation دارای document/section/revision فعلی و مجاز. | متن و quote همان بخش دیده شود. | ناموجود/نامجاز/منسوخ با پاسخ یکسان و بدون افشای وجود سند؛ در history نتیجهٔ منبع‌نامعتبر پنهان می‌شود. |
| حساب‌های مدیر | ایجاد/ویرایش نام، ایمیل، نقش، وضعیت یا password. | ذخیرهٔ اتمی؛ dialog پس از موفقیت بسته؛ تغییر حساس نشست هدف را revoke می‌کند. | آخرین مدیر فعال حفظ؛ duplicate email با 409؛ خطا در dialog و focus صحیح. |
| prompt و تنظیمات | مدیر prompt مشترک و rate/name نصب را مدیریت می‌کند. | یک prompt فعال و نسخهٔ تازهٔ تنظیمات. | ویرایش prompt مدیر دیگر ممنوع؛ انتخاب/ویرایش فعال تأیید می‌خواهد؛ CAS کهنه refresh می‌خواهد. |

میان‌بر ورودی: Enter خط جدید و Ctrl/⌘+Enter ارسال؛ IME، self-grow، کاهش حرکت و صفحه‌کلید حفظ می‌شوند. UI فعلی پیوست در composer ندارد.

## جریان‌های هدف

| شناسهٔ نیاز | جریان هدف | نقطهٔ شکست/کنترل ضروری |
|---|---|---|
| DEMO | اپراتور مقصد ایزوله و corpus ساختگی را انتخاب می‌کند → import → provider محلی → سند ready → سؤال مرجع. | دانلود/حجم و privacy قبل از اقدام؛ DB غیرخالی بدون تأیید تغییر نکند؛ demo با محصول واقعی اشتباه نشود. |
| LOCAL | مدیر چند فایل انتخاب می‌کند → نتیجهٔ per-file → retry انتخابی. | موفقیت جزئی روشن و duplicate retry ممنوع؛ نقش کارمند امکان upload نگیرد. |
| LOCAL | مدیر root alias مجاز را scan می‌کند → preview added/changed/removed → sync و تأیید حذف → job پایدار. | root غایب/scan ناقص حذف نیست؛ مسیر مطلق نمایش داده نشود؛ refresh باعث job موازی بی‌مجوز نشود. |
| ACL | مدیر گروه/عضویت و دامنهٔ سند را تغییر می‌دهد → خلاصهٔ اثر → تأیید → مجوز جاری اعمال شود. | تغییر هم‌زمان، remove عضو در حین تولید و cached title بر اساس policy بازبینی شوند. |
| SSO | کاربر گزینهٔ سازمانی → IdP مشخص → callback معتبر → همان session policy. | لغو، timeout، issuer نامعتبر و linking collision پیام امن؛ مدیر اضطراری بازیابی‌پذیر. |
| DEV | مالک مجاز scope/expiry انتخاب → نمایش یک‌بارهٔ token → client → revoke. | raw token دوباره نمایش/ذخیره در browser نشود؛ disabled owner فوراً اثر کند. |
| OCR | مدیر سند اسکن را وارد می‌کند → extraction queued → OCR محدود صفحه‌های لازم → ready یا failed. | deadline/حجم/دقت، cancel و retry؛ درصد پس از restart حفظ؛ سند ناقص ready نشود. |
| PARSE | مدیر preview متن/صفحه/قطعه را می‌بیند و خطای استخراج را گزارش می‌کند. | خواندن محدود و escaped؛ ویرایش chunk یا اجرای HTML وجود نداشته باشد. |

### پذیرش رابط تازه

برای هر کارت UI، success/loading/empty/error/retry/permission/refresh را با API و browser واقعی بررسی کنید. desktop و ۳۲۰px، RTL متن مختلط، keyboard/focus/dialog و reduced motion بررسی شوند. فقط stateهایی که backend واقعاً پشتیبانی می‌کند نمایش داده شوند؛ route/دکمهٔ آینده در ناوبری جاری اضافه نشود.
