# نقشهٔ راه توسعهٔ متن‌باز

این سند اولویت‌ها را نشان می‌دهد. شرح کار، وابستگی، checkbox و نتیجه فقط در [برنامهٔ اجرا](plans/plans.md) نگهداری می‌شود؛ تسک موازی در tasks/ یا tracker دیگری ساخته نشود.

## اکنون

نسخهٔ منتشرشده تا پارت ۳۱ و اصلاحات بعدی آن است؛ مرجع SHAها برنامه است. توسعهٔ جدید هنوز شروع نشده است. گام بعدی قابل اجرا [۳۲.۱: ممیزی مجوز و دارایی‌ها](plans/plans.md#part-32-1) است و به انتخاب مجوز احتیاج ندارد.

## بعدتر و وابسته به نیاز

- ترجمهٔ کامل UI به انگلیسی: مستندات و README انگلیسی در هدف نزدیک هستند؛ رابط فارسی RTL فعلی حفظ می‌شود تا نیاز ترجمهٔ UI مشخص شود.
- پردازش فرمت‌های PPTX، CSV و HTML هرکدام تسک مستقل در پارت ۳۸ دارند و پس از نمونه/قرارداد آغاز می‌شوند.
- ZIP، sync زمان‌بندی‌شده و webhook پس از ورود گروهی ساده و sync دستی؛ اتصال مستقیم SMB/NFS لازم نیست، میزبان می‌تواند share را read-only mount کند.
- retry/repair و queue جدید باید از همان مهلت کلی، مجوز و سهمیه پیروی کنند.

## مؤجل

Google Drive، Notion، SharePoint cloud و OAuth منابع بیرونی تا دسترسی پایدار و درخواست مستقل. SAML، SCIM، multi-tenant SaaS و rollback کامل نسخهٔ سند نیازمند قرارداد جدا هستند.

## در برنامهٔ فعلی نیست

بازنویسی به LangChain/LangGraph، GraphRAG اجباری، agent با اجرای ابزار/کد، جست‌وجوی آزاد وب، حافظهٔ شخصی نامحدود و streaming پاسخ پیش از حل مرز اعتبارسنجی/مجوز. زیرساخت نو فقط با نیاز محصول و سنجش اضافه شود.

## نقاط بازبینی

پس از هر زیربخش توقف و evidence همان دامنه ارائه شود. پایان هر مرحله، مرور مشترک نیازمندی‌ها و نتایج پیش از شروع دامنهٔ بعدی انجام شود. جزئیات این نقاط در برنامه است.
